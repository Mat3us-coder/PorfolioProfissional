Portfólio pessoal para apresentação formal sobre mim como um desenvolvedor. A case funciona a base de um design simples e funcional, que de fato apresente meu objetivo, competências, projetos, meios de contatos e  projetos pessoais.

A case foi criada com ferramentas como: PHP, Bootstrap, Javascript e MySQL para a criação do banco de dados. Para gestão de projetos de uma forma mais simples, criei um painel de controle para a criação, edição e exclusão de novos projetos com um sistema simples de login para evitar que qualquer um possa entrar e gerenciar os projetos. 

Caso queira utilizar o modelo, colocar credenciais nos campos que faltam do phpmailer e da conexão com o banco de dados.
